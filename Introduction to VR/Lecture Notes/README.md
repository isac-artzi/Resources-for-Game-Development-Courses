## How they work
- One file per topic; a tab per class session (Tuesday / Thursday). Tabs are linkable: `topic-3.html#s2` opens session 2.
- Every file is fully self-contained (CSS and JavaScript inlined, no CDN, no fonts, no images). They work from a
  local download, from GitHub Pages, or from any static host, online or offline.
- Interactive figures (marked ▶) are Canvas 2D visualizations driven by sliders; formulas marked with a blue
  monospace value update live. Topic 6 optionally uses the browser's built-in Web Audio API (click “Enable sound”).
- “Check yourself” questions give immediate feedback. Nothing is transmitted or stored.
- Print: all sessions print in sequence (tabs are hidden in print).

## Reading them
Download the folder (or clone the repository) and open `index.html` in any modern browser — no build step, no server,
no network connection required. The authoring toolchain that generates these pages is maintained separately and is
not part of this repository.
