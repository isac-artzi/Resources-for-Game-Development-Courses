# Advanced Game Testing and Debugging — In-class activities

Thirty activity briefs, one per class meeting, two per week. Each is scoped to 35–60 minutes of real
work and produces an artifact you post as participation evidence. Every activity feeds the graded
assignment for its topic — none of them is busywork, and none of them assigns points.

Activities never require a specific engine build: each one accepts your own project, a provided
sample, or any game you can currently run. They are written to be read in VS Code beside the project
under test, which is why they are markdown rather than web pages.
