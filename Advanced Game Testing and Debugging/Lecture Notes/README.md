panes throughout; no install, no CDN, no network, no accounts.

## How they work
- Start at `index.html`. Each lesson links forward and back, and every lesson links home to the hub.
- Every file is fully self-contained — CSS and JavaScript inlined, no external requests — so a lesson
  works from a local download, from GitHub Pages, or projected in a classroom with no connection.
- Runnable simulators, annotated code walkthroughs where clicking a line explains *why* it is
  written that way, a diagnostic decision tree, and knowledge checks that explain why the wrong
  answers are tempting.
- Every engine-specific section carries both a Unity pane and an Unreal pane.
- The hub links out to the thirty activity briefs in [`../Activities`](../Activities).

## Reading them
Download the folder (or clone the repository) and open `index.html` in any modern browser — no build
step and no server required. The authoring kit used to produce these pages is maintained separately
and is not part of this repository.
